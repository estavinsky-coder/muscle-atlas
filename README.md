# Muscle Atlas (אטלס שרירים)

A one-page study tool for learning muscles: origin, insertion, action, an anatomy illustration with arrows, and animated exercises. The page is in Hebrew.

Open it here: https://estavinsky-coder.github.io/muscle-atlas/
